# Corcho

> No escribas notas. Pega tus ideas.

Prototipo web estático de un tablero de ideas inspirado en un corcho físico.

## Publicar en GitHub Pages

1. Crea un repositorio nuevo llamado `corcho` en GitHub.
2. Sube este proyecto a la rama `main`.
3. En el repositorio, abre **Settings → Pages** y selecciona **GitHub Actions** como fuente.
4. El workflow incluido publicará la web después de cada `push` a `main`.

La página quedará disponible en `https://TU_USUARIO.github.io/corcho/`.
